# Sprint_7 — API-тесты сервиса «Яндекс Самокат»

Проект проверяет обязательные и дополнительные ручки учебного API:

- создание, авторизацию и удаление курьера;
- создание заказа с разными вариантами цвета;
- получение списка заказов;
- принятие заказа;
- получение заказа по трек-номеру.

Тесты независимы. Курьеры удаляются в teardown, созданные заказы отменяются. Если заказ уже принят, teardown завершает его, поскольку API не предоставляет ручку физического удаления заказа.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
pytest
```

## Allure

```bash
pytest --alluredir=allure_results --clean-alluredir
allure serve allure_results
```

В репозитории хранится папка `allure_results` с результатами последнего полного запуска. Сгенерированная HTML-папка `allure-report` исключена из Git.
